Performed full EDA with pairplots, feature distributions, confusion matrix and model accuracy comparison.
**Result → 100% Accuracy across all 3 models**
`Python` `Scikit-learn` `Pandas` `Matplotlib` `Seaborn`

---

**`02`** &nbsp; 🚗 **Car Price Prediction**
> Regression pipeline on 8,000+ real CarDekho records to predict used car selling prices.
Handled string extraction, label encoding, feature engineering (car age), and compared Linear Regression vs Random Forest.
**Result → R² = 0.9835 (98.35% accuracy) with Random Forest**
`Python` `Scikit-learn` `Pandas` `Seaborn` `Matplotlib`
